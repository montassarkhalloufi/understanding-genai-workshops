# Evidence boundaries

All current executable code, prompts, fictional fixtures, and documentation use English. Offline verification appears in `verification/current-offline.json`; PDF extraction output appears in `results/documents-offline.json`.

Historical model measurements discussed in the books were collected under earlier experimental conditions. Original records are retained separately in the author's production archive, not distributed in this repository. They have not been translated and presented as new observations. Changing the language of prompts and fixtures changes experimental conditions; the current implementation does not inherit earlier scores.

Offline checks validate software behavior with controlled fixtures and mocks. They do not establish model quality. No new live model experiment was performed for this release. Use the optional commands in README.md to collect observations in your own environment.
